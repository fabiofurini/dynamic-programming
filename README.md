# Dynamic Programming

Lecture notes on dynamic programming: the principles of dynamic programming and DP algorithms for knapsack problems (0/1, unbounded, bounded, subset sum, multiple-choice, multidimensional, with setups, multiple knapsack), uncapacitated and capacitated lot sizing, coin change and rod cutting, with worked examples, exercises and interactive apps.
